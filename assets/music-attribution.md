# Music attribution

The default royalty-free background track used when rendering the video is:

> **Reverie (small theme)** by **Kevin MacLeod** (incompetech.com)
> Licensed under **Creative Commons: By Attribution 4.0 License**
> http://creativecommons.org/licenses/by/4.0/
> Source: https://incompetech.com/music/royalty-free/index.html?isrc=USUAN1100772

## Required credit

If you publish or share the rendered video, the credit above (or a shortened form, e.g. *"Music: Reverie (small theme) — Kevin MacLeod — CC BY 4.0"*) must appear somewhere visible to the viewer — in the video description, the email accompanying the share, or on-screen.

## Replacing the track

Drop any audio file at `assets/music.mp3` and re-run the render. The script picks up whatever is there. If the file is absent, the script falls back to a silent video.
